# Tugas-Magang-Modul2

## Penjelasan Kode :
Program C++ ini untuk mengontrol kura-kura pada turtlesim agar menggambar spirograph bentuk bunga (Mandala).
Secara garis besar, cara kerja kode ini adalah :
1. Menghitung koordinat (x, y) yang menghasilkan 3 pola spirograph bunga.
2. Memanfaatkan ROS2 service untuk mengubah warna garis, status keaktifan pen, dan berpindah posisi.
3. Menggambar pola spirograph dengan proportional controller.
